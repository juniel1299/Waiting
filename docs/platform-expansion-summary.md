## 지킨 원칙

- **권한은 서버가 매 요청 다시 확인:** 역할 회수·모임 탈퇴·정지가 이미 로그인한 세션의 다음 요청부터 반영된다. 화면 메뉴는 안내일 뿐.
- **중복·경합은 DB 가 최종:** 닉네임·즐겨찾기·소셜 연결은 유일 제약, 역할 변경·채팅 순서·사진 용량은 행·advisory 잠금. 경합 테스트를 실제 PostgreSQL 에서 반복(각 5~20회).
- **삭제 정합성:** 새 데이터(즐겨찾기·연결·채팅·사진)는 FK cascade, 탈퇴는 계정 행을 익명화하므로 연결 데이터를 탈퇴 처리에서 함께 지운다.
- **개인정보 최소화:** 공개 프로필은 닉네임·소개·태그만, 소셜은 공급자 id 만(토큰·이메일 없음), 에러 로그는 비밀번호·토큰·쿠키·이메일·전화를 저장 전에 가림, 사진은 EXIF(위치)를 지운 새 JPEG 만 저장.
- **월 0원:** 새 유료 서비스 없음. 새 의존성은 Zustand(화면 상태)와 TwelveMonkeys imageio-webp(WebP 읽기, 약 564KB) 둘뿐. 실시간 연결 대신 폴링, 차트는 SVG 직접.
