# /tour 모임·커뮤니티 촬영 기록 (2026-11-25 10:49 UTC, 커밋 78c98f46 기준 로컬 프로덕션 빌드)
## 환경
- Spring Boot bootRun(local 프로필, 18080) + Next `next start`(3100), docker PostgreSQL 16(로컬 개발 DB). 운영 사이트에는 로그인하지 않았다.
- 촬영: Playwright 1.64.1 Chromium, 390x844 모바일 뷰포트, 영상은 Playwright 녹화(webm, VP8, 약 15초), 화면 자료는 같은 실행의 스크린샷(780x1688, 2배율).
## 촬영용 데이터
- 계정 3개를 그 자리에서 가입: tour_lead····(모임장), tour_byeol····(새별), tour_haram····(하람). 비밀번호는 실행마다 무작위로 만들고 출력·저장하지 않았다.
- 화면 속 로그인은 녹화 시작 전에 API 로 했다(로그인 화면·비밀번호 입력이 영상에 없음).
- 만든 것: 모임 1개(id 57, 로컬 운영자 계정으로 승인), 모임 공지 1·게시판 글 1(id 444), 댓글·답글·멘션 댓글, 멘션 알림.
## 정리 (API)
- 새 생성자(하람)가 모임 삭제 204 → 세 계정 회원 탈퇴 204·204·204.
## 정리 확인 (로컬 DB SQL)
select (club id 57), (club_member: 모임 57 또는 세 계정), (board_post: 모임 57·글 444·세 계정 작성), (comment: 글 444·세 계정 작성), (notification: 모임 57·세 계정 수신·발신), (탈퇴하지 않은 세 계정)
→ 0|0|0|0|0|0
## 프레임 확인
- 영상을 2초 간격 8장으로 뽑아 확인: 비밀번호·쿠키·토큰·실제 개인정보 없음. 보이는 아이디는 촬영용 가명(tour_byeol····)뿐이다. 모임 홍보 목록에 로컬 e2e 가 남긴 시험 모임 이름이 함께 보인다.
## 남은 확인
- mp4(H.264) 변환은 하지 않았다(이 기기에 ffmpeg 없음). 실제 iPhone Safari 에서의 webm 재생은 확인하지 않았다.
